# Agent 使用模板

不要一上来问“给我数字后端完整路线图”。每天只问能推动你完成当天任务的问题。

## 每天开始

```text
我正在做一个数字后端七天入门项目。今天是第 X 天。
请基于昨天的内容，只给我一个 45 分钟内能完成的小任务。
要求：任务要具体，有产出，不要扩展路线图。
```

## 卡住时

```text
我现在卡在这个概念/代码/错误：
[粘贴内容]

请用数字电路初学者能懂的方式解释。
不要直接展开整套知识体系，只解释我现在完成当前任务必须懂的部分。
```

## 每天结束

```text
这是我今天做的内容：
[粘贴代码、笔记或理解]

请帮我整理成不超过 300 字的学习笔记。
再给我 3 道复习题，以及明天的最小下一步。
```

## 让 agent 当审稿人

```text
请检查我的学习笔记有没有概念错误。
如果有，请指出具体句子，并给出更准确的说法。
如果没有，请告诉我下一步最值得补的一个概念。
```
